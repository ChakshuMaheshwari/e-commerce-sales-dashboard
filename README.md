📊 E-Commerce Sales Dashboard (Excel + Power BI)

📌 Project Overview
This project analyzes E-Commerce sales data using Microsoft Excel and Power BI. The dataset was cleaned, transformed, and visualized to create interactive dashboards that help track sales performance, customer purchasing behavior, and payment trends.

🎯 Objectives
Clean and prepare raw sales data.
Analyze category-wise sales performance.
Track monthly sales trends.
Identify preferred payment methods.
Build interactive dashboards in Excel and Power BI.
Generate actionable business insights.
